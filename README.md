# AR Room — размещение 3D-объектов в реальном помещении (аналог IKEA Place)

Нативное Android-приложение: Kotlin, Jetpack Compose, Google ARCore, SceneView (Filament).

## Возможности
- камера и обнаружение горизонтальных поверхностей (пол, стол);
- каталог из 10 3D-моделей с миниатюрами;
- размещение по тапу, несколько объектов одновременно;
- перемещение, поворот, масштаб жестами + кнопки «меньше / больше / повернуть»;
- выбор объекта тапом, удаление выбранного;
- снимок экрана в галерею (Pictures/ARRoom).

## Как получить APK
1. Создайте репозиторий на GitHub и загрузите туда содержимое этой папки.
2. Вкладка **Actions → Build APK** запустится автоматически (или **Run workflow**).
3. По завершении откройте запуск → раздел **Artifacts** → `ar-room-debug-apk` → внутри `app-debug.apk`.
4. Скопируйте APK на телефон и установите (разрешите установку из неизвестных источников).

Нужен Android 10+ и телефон с поддержкой ARCore (https://developers.google.com/ar/devices).

## Сборка локально
```
bash scripts/fetch_models.sh
gradle :app:assembleDebug
```

## Модели
Скачиваются скриптом из репозитория Khronos glTF-Sample-Assets (лицензии указаны у каждой модели в их репозитории).
Свои модели: положите `.glb` в `app/src/main/assets/models/` и добавьте строку в `Catalog.kt`.
